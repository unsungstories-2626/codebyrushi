About this notebook

CodeByRushi started as a YouTube channel and grew into this — the written version of the same learning.

I'm Rushikesh. I don't come from a computer science background — I build apps every day using an AI coding agent, and I learn the underlying concepts as I go rather than the other way around.

Most tutorials assume you already know the vocabulary. This site doesn't. Every note here is written the way I wish someone had explained it to me the first time — plain language first, jargon only once it's been earned.

What you'll find here

Short, practical notes on programming basics, working with AI coding tools, and the small concepts that trip up beginners the most. No fluff, no filler — if a note doesn't teach you something useful in a few minutes, it doesn't belong here.

Where else to find this

The same ideas, in video form, live on the CodeByRushi YouTube channel. This site exists for anyone who'd rather read than watch, or wants something to refer back to.
